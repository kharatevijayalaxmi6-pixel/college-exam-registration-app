# 🎓 College Exam Registration & Fee Payment App

A modern Android application built to digitize student exam registration, course selection, online fee payment, and digital receipt generation.

## 📱 Features
- 🔐 **Firebase Authentication:** Secure student login and registration.
- 📋 **Dynamic Subject Selection:** Branch and semester-based subject checklists with real-time fee calculation.
- ✅ **Form Validation:** Strict regex verification for college USN format.
- 💳 **In-App Payment:** Seamless checkout powered by the Razorpay Android SDK.
- ☁️ **Cloud Database:** Real-time persistence using Cloud Firestore.
- 📄 **Digital Receipt Generation:** Automatically generates a downloadable PDF receipt on successful payment.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose & Material 3
- **Backend / Database:** Firebase Auth & Firestore
- **Payment Processing:** Razorpay SDK
- **AI Pair Programmer:** Google,Chatgpt
